# 🎨 Random Color Generator

A simple and interactive Random Color Generator built using **HTML, CSS, and JavaScript**.

Each time the user clicks the button, the application generates a random RGB color and displays the corresponding RGB value.

## ✨ Features

- 🎨 Generates random colors instantly
- 🔢 Displays RGB color values
- 🖱️ Simple button-based interaction
- ⚡ Instant color updates
- 📱 Simple and responsive interface

## 🛠️ Tech Stack

- **HTML5** – Page structure
- **CSS3** – Styling and layout
- **JavaScript** – Random color generation and DOM manipulation

## 🎯 How It Works

The application generates random values for the three RGB channels:

- **Red** → 0–255
- **Green** → 0–255
- **Blue** → 0–255

These values are combined to create a random RGB color.
